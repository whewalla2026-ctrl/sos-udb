# Onboarding & First Value Milestones (Lean Phase 2)

- Onboarding flow: sign-up, consent (Phase 1) eased with UI hints and 2-minute target
- First Value: planner block + AI hint in first session
- 24h: ensure a planner plan is auto-generated if user completes onboarding quickly
- Day 3: user has completed 2 planner blocks and used 1 AI hint
- Day 7: user has a full week plan and at least 3 planning edits
