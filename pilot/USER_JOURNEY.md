# Pilot User Journey (Lean Phase 2)

1) Signup: Email-based on-boarding (guided step-by-step)
2) Onboarding: <2 minutes; handshake with basic UUP v2 skeleton; consent already established in Phase 1 pilot path
3) First value moment: Planner shows a simple 1-week plan with 1 or 2 tasks and a first AI hint
4) First week usage: 3-4 planner updates, 2-3 AI hints, occasional planner edits; progress tracked in UUP

Friction points:
- Onboarding cognitive load
- Initial bias toward AI hints vs. human coaching
- Delay in first weekly plan due to context initialization
