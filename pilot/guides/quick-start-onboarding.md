# Quick Start Onboarding (3 Steps, Zero Integrations)

**Goal:** Parent goes from landing page to first weekly plan in under 5 minutes.

## Step 1: Create Account (60 seconds)
- Parent signs up with email + password
- No credit card required for 14-day trial
- No integrations, no wearables, no LMS connection

## Step 2: Add Child Profile (60 seconds)
- Child's first name + age bracket (6-9, 10-12, 13-15, 16-18)
- Choose 2-3 focus areas from simple list:
  - [ ] Reading
  - [ ] Math
  - [ ] Physical activity
  - [ ] Creative time
  - [ ] Life skills
  - [ ] Social time
- That's it. No COPPA consent flow in trial (show notice, gate on payment).

## Step 3: Generate First Weekly Plan (120 seconds)
- AI generates a simple 7-day grid with 1-2 focus blocks per day
- Parent can drag/drop to adjust
- "Send to calendar" option exports .ics
- Parent clicks "Looks good" → first plan is live

## What Happens Next (Day 2-7)
- Child sees today's block(s) on a simple mobile-friendly page
- Checking off a block gives a simple "Nice!" animation
- After 3 check-offs, parent receives push: "Your child completed 3 activities this week!"
- After 7 days, parent gets a weekly summary email with shareable link

## What INTENTIONALLY Does NOT Happen
- No Doter avatar setup required
- No wearable pairing
- No LMS sync
- No Stripe account creation
- No NFT or blockchain
- No AI tutor configuration
- No classroom linking

## Advanced Settings (Gated, Optional)
These are available under "Settings → Advanced" only after the 14-day trial:
- LMS integration (Canvas, Google Classroom)
- Doter avatar customization
- Biometric wearable pairing
- Multi-child dashboard
- Teacher/coach access

## Funnel Tracking (Required Metrics)

| Step | Metric | Target | Warning |
|------|--------|--------|---------|
| Landing page → Signup | Conversion rate | > 5% | < 2% = value prop wrong |
| Signup → Child profile | Completion rate | > 80% | < 60% = friction in form |
| Child profile → Plan generated | Completion rate | > 90% | < 70% = AI plan quality issue |
| Plan generated → Day 2 return | D1 retention | > 40% | < 20% = no aha moment |
| Day 7 → Trial conversion | Paid conversion | > 10% | < 5% = pricing or value issue |
