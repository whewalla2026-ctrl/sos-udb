# Pilot User Personas (Lean Phase 2)

- Persona 1: BusyParent Brenda
  - Role: Parent, ages 35-45, tech-savvy but time-limited
  - Goals: Easy weekly planning view, clear progress signals, minimal cognitive load
  - Engagement: Moderate to high; appreciates automation that reduces cognitive load

- Persona 2: Self-Directed Student Sam
  - Role: High school student, 15-17, comfortable with tech
  - Goals: Quick wins, tangible skill progress, clear feedback
  - Engagement: High; will explore features and give feedback on UX

- Persona 3: Teacher-Advisor (optional in pilot scope)
  - Role: Teacher/School partner evaluating student progression
  - Goals: Simple integration path to track student progress in classroom contexts
  - Engagement: Low in Phase 2, but critical for adoption in Phase 3+ if rolled out wider.
