# Pilot Feedback Template
- Daily feedback: What did you try today? What worked or not? Any blockers?
- Weekly feedback: What one feature would improve the product this week? Any friction on onboarding or planning?
- In-app feedback prompts: rate experience 1-5 on clarity, speed, and usefulness; optional free-text.
- Categorization guide: UX, Performance, Value, Data Security, AI Reliability
