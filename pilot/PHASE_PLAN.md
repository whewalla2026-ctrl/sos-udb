# Pilot Plan: Lean Phase 2 (UDB) – Controlled Rollout

Scope:
- Phase A: 10 users (internal/friendly) – validate lean UUP v2, AI-lite hints, planner, and cost guardrails.
- Phase B: 30 users (early adopters) – validate onboarding, basic LMS context (mocked), use of vector fallback, monitoring maturity.
- Phase C: 100 users (real validation) – validate end-to-end flow with live data paths and guardrails in production-like environment.

Timelines:
- Phase A: 14 days
- Phase B: 21 days
- Phase C: 28 days

Exit criteria (per phase):
- Phase A: Value evidenced within 2 minutes; TTV <= 2 minutes for onboarding; no critical blockers; budget guardrails inertially protecting costs.
- Phase B: >90% onboarding completion; WAU rising; AI hints used with expected distribution; vector fallback engaged if needed; costs within guardrails.
- Phase C: 85% retention across the week; net-new users > threshold; latency targets met; no critical data issues.

Go/No-Go gating: evidence-based; a governance sign-off is required to advance.
