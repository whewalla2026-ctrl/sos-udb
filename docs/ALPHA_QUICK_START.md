# UDB Quick Start Guide for Families

## 1. Create Your Account

1. Go to http://localhost:3030
2. Click **Register**
3. Enter your email, create a strong password (12+ chars, uppercase, lowercase, digit, special char)
4. Verify your email address

## 2. Add Children to Your Family

1. Log in to your parent account
2. Go to **Family Dashboard** (`/dashboard/family`)
3. Click **Add Child**
4. Enter child's name and age
5. For children under 13: complete COPPA verification (parent confirms consent)
6. Child receives login credentials via the dashboard

## 3. Exploring the Dashboard

| Section | What You'll Find |
|---------|------------------|
| Dashboard | Daily overview: quest progress, streaks, notifications |
| Quests | Available learning quests for each child |
| Goals | Set learning goals and track progress |
| Family | Manage family members and permissions |
| Analytics | Track time spent, skills gained, streaks maintained |

## 4. Completing a Quest

1. From **Quests**, select a quest for your child
2. Child works through the quest steps
3. AI tutor provides hints and feedback
4. Upon completion, points are awarded and streak is updated

## 5. Key Features

- **Daily Streaks**: Encourage daily learning — miss a day and auto-freeze kicks in
- **AI Tutor**: Contextual hints during quests (after completion attempt)
- **Points & Badges**: Earned through quests and consistent engagement
- **Notifications**: Weekly progress reports and milestone celebrations

## 6. Troubleshooting

| Issue | Solution |
|-------|----------|
| Can't log in | Use "Forgot Password" on the login page |
| Child can't see quests | Check age-appropriate quest settings in Family Dashboard |
| AI tutor not responding | Refresh the page — AI service may need a moment |
| Slow loading | Wait a few seconds and refresh — platform is warming up |

## 7. Known Limitations

See `docs/KNOWN_LIMITATIONS.md` for full details. Key items:
- AI feedback requires an active internet connection
- Some features are behind feature flags (being enabled gradually)
- Quest Store is not yet available

## 8. Getting Help

- **Critical issues** (can't log in, data missing): Email alpha-support@sos-udb.com
- **General questions**: Reply to your welcome email
- **Response SLA**: Critical < 24h, General < 72h
